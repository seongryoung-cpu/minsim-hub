
# 한국 지도 정확한 SVG 경로 구현 계획

## 목표
지역 선택 화면의 한국 지도를 실제 한국 지도 형태에 맞는 정확한 SVG 경로로 교체합니다.

---

## 1. 현재 상태

| 항목 | 현재 상태 |
|------|----------|
| 지도 형태 | 간소화된 다각형 (육각형 모양) |
| 정확도 | 매우 낮음 - 실제 지형과 다름 |
| viewBox | "0 0 320 430" |

---

## 4. 기술적 세부 사항

### 4.1 REGION_PATHS 데이터 구조 변경

```text
기존:
{
  '서울특별시': {
    path: 'M145,95 L155,90 L165,95...',  // 간단한 다각형
    label: { x: 155, y: 102 }
  }
}

변경 후:
{
  '서울특별시': {
    path: 'm 133.25429,127.63884 0.58,0.33...',  // 정확한 경계선
    label: { x: 155, y: 130 }  // 새 위치에 맞게 조정
  }
}
```

### 4.2 viewBox 변경

```text
기존: "0 0 320 430"
변경: "0 0 524 631"
```

### 4.3 스타일 조정

- 지도가 더 넓어지므로 `maxHeight` 조정
- 작은 지역(서울, 세종 등)의 라벨 표시 로직 유지
- 선택/호버 효과 그대로 유지
