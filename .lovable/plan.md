# 화면별 점검 계획 (일반 사용자 + 공론)

이번 작업은 **점검과 목록 작성만** 합니다. 코드나 데이터는 바꾸지 않습니다. 결과 목록을 보시고 고칠 항목을 골라 주시면 그때 작업합니다.

## 점검할 화면
- 일반: 홈, 선거, 후보 상세, 후보 비교, 뉴스, 퀴즈/리더보드, 정치 MBTI·성향 테스트, 정책 매칭, 마이페이지, 알림 설정, 앱 정보/FAQ/약관, 404
- 공론: 공론 허브, 의제 상세, 주장(Claims), 빠른 투표, 홈 공론 배너

## 화면마다 확인할 것
1. 버그·오류: 화면이 깨지는지, 콘솔 에러, 동작하지 않는 버튼/링크
2. 하드코딩: DB가 아닌 코드에 박힌 문구·목록·가짜 데이터 (예: 홈 팁 문구, 빠른 메뉴, mockLeaderboard 등)
3. 디자인·사용성: 모바일(393px)·데스크톱 화면, 빈 화면/로딩 표시, 글자 넘침
4. 미완성 기능: 연결 안 된 메뉴, 만들다 만 기능

## 진행 방법
- 실제 브라우저로 각 화면을 모바일·데스크톱 크기로 열어 스크린샷 확인 (로그아웃/로그인 상태 모두)
- 각 화면의 코드를 읽어 하드코딩과 미완성 부분 확인

## 결과물
화면별 표로 정리: 문제 / 종류(버그·하드코딩·디자인·미완성) / 중요도(높음·중간·낮음) / 제안 수정 방법.
보신 뒤 고칠 항목을 골라 주시면 별도 계획으로 진행합니다.
