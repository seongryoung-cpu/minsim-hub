# 선거 일정·체크리스트 DB 이전 계획

## 목표
코드에 고정된 선거 이름·날짜·진행 단계·투표소 날짜·체크리스트를 DB로 옮기고, 선관위 공식 일정으로 바꿉니다. 관리자 화면에서 고칠 수 있게 합니다.

## 새로 만드는 표 (2개, 비슷한 용도의 기존 표 없음)
1. **선거(elections)**: 선거 이름, 정식 명칭, 선거일, 현재 선거/다음 선거 표시, 순서
2. **선거 일정 항목(election_schedule_items)**: 선거별 항목, 종류(진행 단계 / 투표 일정 / 체크리스트), 제목, 짧은 이름, 시작·종료일, 외부 링크, 순서

누구나 읽기 가능, 관리자만 수정 가능.

## 넣을 실제 일정 (작업 때 선관위 공식 자료로 다시 확인)
- 2026 제9회 전국동시지방선거 (선거일 2026.06.03)
  - 진행 단계: 예비후보 등록(시·도지사 2026.02.03~) → 후보자 등록(05.14~15) → 선거운동(05.21~06.02) → 당선 확정(06.03)
  - 투표 일정: 사전투표 05.29~30, 선거일 06.03 (선관위 투표소 찾기 링크)
  - 체크리스트: 선거인명부 확인, 투표소 위치 확인, 후보자 정책 비교 (기존 문구 유지)
- 2028 제23대 국회의원선거 (선거일 2028.04.12) — 다음 선거

## 바뀌는 화면 (요청 범위)
- 선거 화면: 진행 단계, 투표소 날짜, 체크리스트를 DB에서 불러옴 (보기만)
- 홈: D-Day, "다음 선거" 안내, 당선인 카드의 선거 이름을 DB에서 불러옴
- 관리자: 기존 관리자 메뉴에 "선거 일정" 화면 추가 (선거 추가·수정, 항목 추가·수정·삭제·순서)

진행 단계 이름이 "예비후보/당내경선/본선대결/당선확정"에서 실제 일정 이름으로 바뀝니다.

## 기술 메모
- 마이그레이션: 두 표 생성 + GRANT(anon/authenticated SELECT, service_role ALL) + RLS(공개 읽기, `has_role(auth.uid(),'admin')` 쓰기) + 초기 데이터
- `useElections` 훅(react-query)로 현재/다음 선거와 항목 조회; `src/types/election.ts`의 `CURRENT_ELECTION`, `NEXT_ELECTION`, `BASE_MILESTONES` 제거하고 계산 함수는 인자로 받은 데이터 사용
- 사용처: `Election.tsx`, `Home.tsx`, `ElectedOfficialCard.tsx`, `ElectionTimeline.tsx`
- 로딩 중·데이터 없음 표시 추가; 관리자 화면은 `AdminSettings` 패턴 참고
